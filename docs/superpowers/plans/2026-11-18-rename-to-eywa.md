# Rename to Eywa Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rename every Cusco name in the code, tests and docs to Eywa, with no behavior change and no compatibility code.

**Architecture:** A mechanical rename in two passes. The tests are renamed first so they fail to compile against the old crate, then the crate and source follow. The docs are a separate pass with one rewritten paragraph.

**Tech Stack:** Rust 1.88+, Cargo, BSD `sed` under zsh.

**Spec:** `docs/superpowers/specs/2026-11-18-rename-to-eywa-design.md`

## Global Constraints

- Replace `cusco` → `eywa`, `Cusco` → `Eywa`, `CUSCO` → `EYWA`. That one rule produces every row of the spec's table (`EYWA_DIR`, `io.github.samctensen.eywa`, `/Cellar/eywa/`, `~/.grok/hooks/eywa.json`, `.json.eywa-tmp`, `is_eywa_hook`, `github.com/samctensen/eywa`, …).
- Clean break: no file outside the excluded docs below may match `cusco` in any case once the plan is done. Nothing reads, matches or migrates a Cusco install.
- The API does not change: every message, field and value, and protocol version `1`.
- These keep "cusco" as historical records: `docs/superpowers/plans/2026-11-18-alert-latency.md`, `docs/superpowers/plans/2026-11-18-cusco-v0.1.md`, `docs/superpowers/specs/2026-11-18-alert-latency-design.md`, `docs/superpowers/specs/2026-11-18-rename-to-eywa-design.md`, and this plan.
- Shell is zsh with BSD `sed`: edit in place with `sed -i ''`, and quote paths.
- Commits carry no `Co-Authored-By` line.

## Review Focus

- A user-visible string that still says cusco (an error message, a path, a launchd label): the final `git grep` in each task must come back empty.
- `eywa setup` must write hooks that run the `eywa` binary, and `--remove` must find them again. The renamed setup tests in `tests/service.rs` cover this.
- A Homebrew install must resolve `/Cellar/eywa/` to the prefix's `bin/eywa`. No test exercises `stable_executable`, so Task 1's grep is the check.
- `rustfmt` may reflow lines that got shorter. Task 1 runs `cargo fmt` before `--check`.
- `cargo install --git` and the schema `$id` must point at `samctensen/eywa`. Task 2's grep covers both.

### Task 1: Rename the crate, binary and installed names

**Files:**
- Modify: every file under `tests/` that matches `cusco`
- Modify: `Cargo.toml` (`[package] name`, `[[bin]] name`), `Cargo.lock` (regenerated by the build)
- Modify: every file under `src/` that matches `cusco`

**Interfaces:**
- Produces: crate `eywa`, binary `eywa`, env vars `EYWA_DIR` and `EYWA_RECORD`, `eywa::launchd::LABEL == "io.github.samctensen.eywa"`, `eywa::launchd::LOG == "eywa.log"`, test helpers `run_eywa` and `run_eywa_env` in `tests/common/mod.rs`.

- [ ] **Step 1: Rename the tests.** `git grep -l -I -i cusco -- tests | while read -r f; do sed -i '' -e 's/cusco/eywa/g' -e 's/Cusco/Eywa/g' -e 's/CUSCO/EYWA/g' "$f"; done`

- [ ] **Step 2: Run them.** `cargo test --no-run`. Expected: does not compile, "unresolved import `eywa`" or "use of undeclared crate or module `eywa`".

- [ ] **Step 3: Rename the crate and source.** Run the same loop over `-- Cargo.toml src`, then `cargo fmt`.

- [ ] **Step 4: Run everything.** `cargo test`, `cargo clippy --all-targets`, `cargo fmt --check`. Expected: all pass, no warnings.

- [ ] **Step 5: Check nothing is left.** `git grep -n -i cusco -- Cargo.toml Cargo.lock src tests`. Expected: no output.

- [ ] **Step 6: Commit.**

```bash
git add -A Cargo.toml Cargo.lock src tests
git commit -m "refactor: rename the crate and binary to eywa"
```

### Task 2: Rename the docs

**Files:**
- Modify: `README.md`, `docs/api.md`, `docs/api-v1.schema.json`, `docs/design.md`, `docs/research/*.md`

- [ ] **Step 1: Rename.** `git grep -l -I -i cusco -- README.md docs ':!docs/superpowers' | while read -r f; do sed -i '' -e 's/cusco/eywa/g' -e 's/Cusco/Eywa/g' -e 's/CUSCO/EYWA/g' "$f"; done`

- [ ] **Step 2: Rewrite the name paragraph** in `docs/design.md`. After Step 1, it is the paragraph that now begins "The name comes from the Inca capital" (lines 16–18). Replace the whole paragraph with exactly:

```markdown
The name comes from Eywa, the great tree in Avatar that connects every living
thing on Pandora. Here every agent, session, turn and request is a node in one

```

- [ ] **Step 3: Read the changed prose.** `git diff -- README.md docs` and check that each changed sentence still reads correctly. A Markdown table's column widths don't matter, since the tables use `| --- |`.

- [ ] **Step 4: Check nothing is left.** `git grep -n -i cusco -- . ':!docs/superpowers'` gives no output, and `git grep -l -i cusco -- docs/superpowers` lists only the five files in Global Constraints.

- [ ] **Step 5: Commit.**

```bash
git add README.md docs
git commit -m "docs: rename Cusco to Eywa"
```
